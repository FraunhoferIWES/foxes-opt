Examples
========

Python scripts
--------------

The `examples folder on GitHub (main branch)
<https://github.com/FraunhoferIWES/foxes-opt/tree/main/examples>`_ contains
Python scripts and parameter-file cases for wind-farm optimization.
Start with ``layout_single_state`` for layout optimization or
``wake_steering`` for turbine yaw optimization. Other examples cover wind
roses, regular grids, geometry-only problems, and YAML input.
